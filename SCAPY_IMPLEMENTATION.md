# Scapy Implementation - Network Security Tools

## WiFi Scanner
- Detects wireless networks using nmcli/iwlist
- Classifies security (WPA2/3, WEP, Open)
- Identifies vulnerable configurations

## Port Scanner
- TCP SYN scan using Scapy
- Service detection
- Vulnerability analysis for common ports

## Device Discovery
- ARP scanning for local network enumeration
- MAC vendor lookup
- Device classification (printer, router, camera, IoT)
- Port-based fingerprinting

All tools export to JSON/HTML/PDF for forensic analysis.
